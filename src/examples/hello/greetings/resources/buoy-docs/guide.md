# Getting started

Follow the repository's runnable BPM walkthrough to install this package.
Open **Help > Documentation** in Studio and choose **Greetings** to read its
documentation together with the upstream Buoy reference.

## Inspect the API

The [Message function](api/message.md) returns a greeting. Use the copy button
on its code block to copy the source with its original indentation.

| Item | Purpose |
| --- | --- |
| `modules/Greeter.bui` | Package API |
| `resources/buoy-docs/` | Offline documentation and local images |
