# Greetings

The greetings package supplies a message for the runnable BPM walkthrough.
Its documentation travels inside the same archive as its modules, so Studio
can show this guide alongside the Buoy language reference without a network.

## Get started

Install the package from the [BPM walkthrough](guide.md), then read the
[Message API](api/message.md).

## Documentation conventions

Pages describe their meaning in front matter. Studio supplies the typography,
navigation, breadcrumbs, code colors, and copy buttons. Relative links stay
within this installed package version.
